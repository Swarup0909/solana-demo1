IMPORTANT: RUST MUST BE INSTALLED FIRST
===============================================

Since Rust is not currently installed on your system,
you MUST install it before running this project.

STEP 1: INSTALL RUST
--------------------

Run this command in your terminal:

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Follow the prompts and choose option 1 (default).

After installation, run:

    source $HOME/.cargo/env

Verify installation:

    rustc --version
    cargo --version

You should see version numbers displayed.

===============================================
QUICK START (After Rust is Installed)
===============================================

1. Navigate to project directory:

    cd /Users/swaruppatil/Desktop/solidity/demo1-solana

2. Run the automatic installer:

    chmod +x scripts/install.sh
    ./scripts/install.sh

3. Start the server:

    RUST_LOG=info cargo run

4. Open browser:

    http://localhost:3000

That's it! You should see the live price monitor.

===============================================
ALTERNATIVE: MANUAL BUILD
===============================================

1. Check dependencies:

    cargo check

2. Build for production:

    cargo build --release

3. Run the binary:

    ./target/release/solana-price-monitor

===============================================
BEFORE PRODUCTION USE
===============================================

⚠️  VERIFY POOL ADDRESSES:

    ./scripts/verify-pools.sh

The pool addresses in src/config.rs are EXAMPLES.
You must verify them on Solscan.io before production.

⚠️  GET PREMIUM RPC:

Free Solana RPC has rate limits. For production:
- Helius: https://helius.xyz (recommended)
- QuickNode: https://quicknode.com
- Alchemy: https://alchemy.com

Then set:

    export RPC_URL="your_premium_rpc_url"

===============================================
TROUBLESHOOTING
===============================================

Problem: "cargo: command not found"
Solution: Install Rust (see STEP 1 above)

Problem: Rate limit errors
Solution: Get premium RPC endpoint

Problem: Prices show as 0.00000000
Solution: Verify pool addresses (./scripts/verify-pools.sh)

Problem: WebSocket disconnects
Solution: Check firewall, ensure port 3000 is open

For more help, see SETUP.md
